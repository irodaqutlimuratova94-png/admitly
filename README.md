# Admitly — University Application Coach

A self-contained front-end prototype for university application planning.

## Run locally
1. Extract this folder.
2. Open `index.html` in a modern web browser.

No build step is required. The current prototype includes the motivation-letter checklist, curated university directory with external worldwide search links, CV builder, and demo-only sign-in form. The directory is not exhaustive; the sign-in form is not connected to real authentication.
